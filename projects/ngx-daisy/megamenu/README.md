# ngx-daisy/megamenu

Standalone Angular megamenus with daisyUI appearance. See the [component guide](../../../docs/remaining-components.md) for imports, APIs, examples and behavior. Showcase: `/megamenus`.

## daisyUI alignment

Trigger spacing, border, arrow and expanded state follow native dimensions. A theme-aware active surface follows pointer/selected triggers, including resize changes; reduced motion disables its transitions. CDK still owns the portalled panel and keyboard focus, so no browser popover JavaScript is required.
