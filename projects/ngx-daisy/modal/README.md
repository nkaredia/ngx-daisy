# Modal

See the [Actions integration and API guide](../../../docs/actions.md#modal) for composition, inputs, accessibility and customization.

## daisyUI alignment

Default scale and timing now follow daisyUI's 0.95 scale/300ms transition, and panel height is no longer arbitrarily capped below the viewport. CDK modal focus, inertness, nesting, Escape and scroll locking are retained.
