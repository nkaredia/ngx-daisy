# ngx-daisy/carousel

Standalone Angular carousel family with daisyUI styling. See the [Data Display guide](../../../docs/data-display.md) for exports, examples, behavior and customization.

## daisyUI alignment

Slides use their intrinsic width by default. `slideSize="full"` retains viewport-width slides; update existing full-screen examples to opt in. `viewportClass` styles the internal viewport (for example gaps and vertical height). No fixed vertical height is imposed. Project width utilities on slide elements for multiple-visible-slide layouts. Inactive slides remain inert, and CDK-style keyboard/navigation state remains app controlled.
