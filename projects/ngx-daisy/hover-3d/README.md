# @ngx-daisy/cdk/hover-3d

Standalone Angular hover-3d family with daisyUI styling. See the [Data Display guide](../../../docs/data-display.md) for exports, examples, behavior and customization.

## daisyUI alignment

Uses native hover-3d perspective, rotation, shine, shadow and easing. Pointer input supplies the native CSS variables; transparent, noninteractive zones preserve projected link/button clicks. Disabled and reduced-motion states suppress the visual effect.
