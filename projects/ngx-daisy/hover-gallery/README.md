# ngx-daisy/hover-gallery

Standalone Angular hover-gallery family with daisyUI styling. See the [Data Display guide](../../../docs/data-display.md) for exports, examples, behavior and customization.

## daisyUI alignment

Hovering across the image now selects the native image zones; leaving restores the first image. Up to ten images are shown. Focus the image stage and use Left/Right, Home or End for keyboard selection. Numbered controls are optional (`controls`, default false); set `[controls]="true"` to retain the previous controls and provide touch buttons. `activeIndex` remains a model.
