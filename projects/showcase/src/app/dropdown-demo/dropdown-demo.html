Action menu
Use menu mode for a short list of commands. Each item performs one action; selection closes the menu.
Content panel
Use kind="content" for preferences and native form controls. Keep persistent values in your component, because panel content is recreated when opened.
Choosing a value
Use Select when people need to choose a form value. A dropdown trigger represents an action, rather than the current selection.
