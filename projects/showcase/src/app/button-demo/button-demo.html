Choose the right control

Choose behavior first. The visual treatment comes after it.

Run an action
Use <button dsyButton> to save changes, open a dialog or submit a form. Name the action with a clear verb.
Go somewhere
Use <a dsyButton> with href or RouterLink for a destination. It keeps native link behavior.
Set the emphasis
Give the main action the strongest treatment. Use a quieter variant for secondary actions, and pair semantic color with meaningful text.
