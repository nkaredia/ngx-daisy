# WCAG 2.2 AAA support ledger

Source under review: `972cb26` (web only). [Normative criteria and conformance requirements](https://www.w3.org/TR/WCAG22/). These dispositions describe capability and evidence, not certification. AAA includes all applicable A and AA criteria. The [55-criterion A/AA ledger](../wcag-review.md) is historical: A03–A09 and D04 have subsequent remediation recorded in [fixes](../../../web-accessibility-fixes.md); its original failures must not be read as a current retest. Contrast remains unresolved and manual dispositions remain open. Together that ledger and the 31 rows below account for all 86 current criteria; obsolete 4.1.1 is excluded.

`Gap` means evidence contradicts default AAA support. `Partial` means code/API support exists but the full criterion has not been verified. `Consumer` means content/process configuration belongs to the app; it is not automatically a pass or universally inapplicable. `Manual` means the required verification has not been completed.

## Focus-area evidence

For a rectangular target of width `w` and height `h`, the reference 2px perimeter area is `4w + 4h`. A 2px ring fully inset within that rectangle has area `4w + 4h - 16`, before accounting for rounding or other changed pixels. This source observation is a specific reason not to treat our 2px inset outlines as verified AAA focus appearance. An actual rendered test must also establish 3:1 contrast between focused and unfocused pixels; adjacent-color contrast alone tests a different relationship. No automatic failure is assigned where additional fill changes might supply the required area.

## Explicit verification limits

The browser batch covers settled default examples and currently mounted content, not all input combinations or open overlays. It does not execute consequential workflows, classify every target exception, measure focus pixels, emulate screen readers, prove reflow at browser zoom, or validate reduced motion. All 35 actual shipped presets are included; custom themes need independent checks. Theme Builder is outside the 70 component-route batch. Syntax-highlighted source text is excluded per the user; its tabs/buttons remain included. This exclusion prevents treating the audit as a complete showcase-page conformance assessment.
