# WCAG 2.2 A/AA review ledger

This ledger prevents “no axe finding” from being mistaken for a pass. It covers applicable A and AA criteria, not AAA. A component library cannot establish whole-application conformance for consumer content, authentication, transactions or media. Findings refer to the main report. “Partial” means evidence was collected but the criterion is not fully established; “manual” means further manual verification is required. None of these labels is a certification.
